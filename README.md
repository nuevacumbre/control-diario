# Control Diario - Sistema para Choferes de Locomoción Pública

Aplicación mobile-first para control diario de ingresos con Vue 3.

## 🌟 Características

- 📱 Diseño mobile-first responsive
- 🔐 Login seguro con variables de entorno
- 📅 Calendario con feriados de Chile
- 💰 Control de ingresos diarios con 30% de ganancia
- ✓ Checkbox para colaciones (+$5.000)
- ✨ Campo de viáticos extra (montos adicionales)
- 📊 Gráficos interactivos con Chart.js
- 📈 Reportes mensuales y análisis de tendencias
- 💾 Almacenamiento local en JSON (editable)
- 🌓 Tema claro/oscuro con glassmorfismo
- ⚡ Renderizado optimizado
